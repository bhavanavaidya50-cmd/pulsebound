# PULSEBOUND – Screenshots & Visual Assets Guide

This directory holds visual assets, game captures, and demo materials for the PULSEBOUND prototype.

### Captured Scenes:
1. `01_main_menu.png` – Animated main menu with neon title, ambient particles, Play, Level Select, and How to Play modals.
2. `02_level1_pulse_activation.png` – The Wanderer triggering the cyan Pulse shockwave, revealing hidden quantum platforms over the chasm.
3. `03_level2_shadow_forest.png` – The Shadow Forest biome with patrolling Void Creepers, hovering Sentinels, and floating bioluminescent spores.
4. `04_level3_lost_temple.png` – The Lost Temple trial with multi-axis moving platforms, laser hazards, and intricate crystal paths.
5. `05_level_complete_modal.png` – Performance summary with 3-star rating, crystal collection count, speed bonus, and Next Level navigation.
6. `06_victory_screen.png` – Grand Victory Screen celebrating all-realm completion with total score and Pulse Master rank.
7. `07_mobile_touch_controls.png` – On-screen glassmorphic touch overlay demonstrating mobile playability.
